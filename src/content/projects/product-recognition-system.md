Built an applied product-recognition system for catalog-scale machine learning. Improved on-device classification across 60+ categories, added Google Vision API as a fallback, automated processing of 35,000+ product images with Playwright, and connected 45,000+ items in a product knowledge graph. Designed a Vertex AI continuous-learning loop for cloud-verified predictions and retraining.
